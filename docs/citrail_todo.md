## 1. パスファインダーへの複数ノード選択方法の改善（2026-07-25 セッション、相談・仕様確定・未実装）

**現状の課題**：Citrailからパスファインダーへノードを送る際、現在は「ノードをクリック→詳細パネルを開く→チェックボックスでパスファインダー送信対象にする」という操作を1件ずつ繰り返す必要があり、複数ノードを送りたいときに手間がかかる。

**検討の経緯**：まず「Ctrl(Cmd)+クリックでのトグル選択＋Ctrl+ドラッグでの範囲選択」という案を提示したが、Yujinさんからの代案（以下）を採用することになった。

**採用する仕様（確定・未実装）**：
1. 専用ボタン「パスファインダーに送るためのノードを選択」をクリックすると、選択モードに切り替わる
2. 選択モード中は、キャンバス全体にうっすら色を重ねて（背景色調を変更するなど）、通常モードと視覚的に区別できるようにする
3. 選択モード中は「選択モード中：◯件選択済み」のような件数表示を常に出す
4. 選択モード中にノードをクリックすると、**詳細パネルは開いたまま**にし（内容を見ながら選ぶ必要があるため）、それと同時にそのノードのパスファインダー送信対象のON/OFFも切り替える（📌マークで選択状態を表示。既存の`togglePf()`/`pfSelection`の仕組みをそのまま流用できる想定）

6. 専用の「キャンセル」ボタンを用意し、これを押すと送信せずに通常モードへ戻る（選択モードに入る前の状態、または選択自体は維持されるかは実装時に要確認・小さな論点）
